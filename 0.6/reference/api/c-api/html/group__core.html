◆ TLV_TAG_CAPACITY

#define TLV_TAG_CAPACITY   8

Inline storage capacity of a tlv_tag_t, in bytes (default 8).

Must be between 1 and TLV_TAG_MAX_SUPPORTED_SIZE.

Warning
This affects the layout of tlv_tag_t and everything containing it, so it is part of the ABI. Override it consistently when building the library and every consumer.

◆ TLV_TAG_MAX_SUPPORTED_SIZE

Fixed uint8_t representation limit for tag sizes.

This is not a configurable or protocol limit; defining it before including this header is a compile-time error.

◆ tlv_result

enum tlv_result

Result code returned by OpenTLV C functions.

Zero is success; every other value is an error. Unless a function states otherwise, an error leaves its output parameters unchanged. Which codes a function can return is documented on that function.

See also
tlv_strerror
Enumerator
TLV_OK 

The operation succeeded.

TLV_ERR_BUFFER_TOO_SHORT 

A supplied buffer is too small for the data or output required.

TLV_ERR_INVALID_LENGTH 

A length is malformed, out of range, or not representable as size_t.

TLV_ERR_NULL_ARG 

A required pointer argument is NULL.

TLV_ERR_OUT_OF_MEMORY 

An allocation failed.

TLV_ERR_END_OF_BUFFER 

No further element exists, or the input is empty.

TLV_ERR_INVALID_TAG 

A tag is malformed or invalid for the format or profile.

TLV_ERR_VISITOR 

A visitor callback requested an error stop.

TLV_ERR_LIMIT 

A configured depth, size, or element-count limit was exceeded.

TLV_ERR_SCHEMA 

Input violates a schema rule; see tlv_schema_validate().

TLV_ERR_INVALID_ARG 

An argument has an invalid value that no more specific code describes.

TLV_ERR_INVALID_TAG_SIZE 

Tag size violates the range supported by the operation.

TLV_ERR_INVALID_BYTE_ORDER 

Byte order is unknown or unsupported.

TLV_ERR_OVERFLOW 

Unsigned value cannot fit the requested numeric width.

TLV_ERR_INVALID_VALUE 

Universal primitive content is malformed or fails a canonical DER rule.

TLV_ERR_UNSUPPORTED_TYPE 

Universal tag number has no implemented canonical validation.

TLV_ERR_SCHEMA_MISSING 

A required field is absent (tlv_schema_validate()).

Reported when a rule's min_occurs exceeds its actual occurrence count. It is distinct from TLV_ERR_SCHEMA because its error offset is the end of the enclosing parent's value: a scope boundary, not an element. That offset can coincide with the start of an unrelated sibling in the parent scope, so a tag read there is not reliably the cause.

Every other tlv_schema_validate() violation (forbidden or unknown tag, duplicate or excess occurrence, kind mismatch, invalid rule table) returns TLV_ERR_SCHEMA with an offset anchored to the actual element.

◆ tlv_read_u16_be()

uint16_t tlv_read_u16_be ( const uint8_t *  data)

Reads a 16-bit unsigned integer from raw bytes, big-endian.

Converts raw value bytes independently of host byte order and TLV profile. No bounds checks are performed and no alignment is required; only the specified bytes are read. Every value of the declared integer type fits, so no overflow is possible.

Parameters

Warning

◆ tlv_read_uint()

tlv_result_t tlv_read_uint ( const uint8_t *  data,
size_t  width,
tlv_byte_order_t  order,
uint64_t *  value 
)

Reads an unsigned integer of 1..8 bytes with an explicit byte order.

Accepts zero padding. The read finishes before *value is stored. There is no allocation, implicit native byte order, or protocol validation. Byte buffers need no alignment.

Validation order: required NULL pointers, then the width, then the byte order.

Parameters
[in]dataSource bytes; width readable bytes. Allocation bounds are not checked.
[in]widthNumber of bytes, 1..8.
[in]orderByte order of the bytes.
[out]valueReceives the value; must point to a writable uint64_t.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG if a required pointer is NULL.
TLV_ERR_INVALID_LENGTH if width is unsupported.
TLV_ERR_INVALID_BYTE_ORDER if order is unknown or unsupported.
Note
On failure *value is unchanged.

◆ tlv_tag_equal_u16()

tlv_result_t tlv_tag_equal_u16 ( const tlv_tag_t *  tag,
uint16_t  value,
tlv_byte_order_t  order,
int *  equal 
)

Compares a tag numerically against a 16-bit value.

Interprets the tag as an unsigned integer as tlv_tag_to_u64() does, with the same input errors, and compares it to value. Zero padding at the most significant end does not affect equality. The tag value is never truncated to the argument type.

Required pointers are checked before the tag size, then the byte order.

Parameters
[in]tagTag to compare.
[in]valueValue to compare against.
[in]orderByte order of the tag bytes.
[out]equalReceives 1 for equality, 0 for mismatch. Must point to a writable int.
