Copies an exact encoded byte range, preserving the original wire bytes.

The caller identifies the range (for example input + offset and consumed from tlv_read() or tlv_scan()) as a native pointer/length pair. No framing validation is performed. Overlap is supported.

Parameters
[in]encoded_dataEncoded bytes to copy. May be NULL only when encoded_length is zero.
[in]encoded_lengthNumber of bytes to copy.
[out]dataDestination buffer. NULL with zero capacity queries the required size.
[in]capacityDestination capacity in bytes.
[out]writtenReceives encoded_length (the required size for a query).
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG for missing required pointers.
TLV_ERR_BUFFER_TOO_SHORT if capacity is insufficient.

Copies only a view's value, without interpreting or validating the tag.

Overlapping source and destination byte ranges are supported.

Parameters
[in]viewView whose value is copied.
[out]dataDestination buffer. NULL with zero capacity queries the required size.
[in]capacityDestination capacity in bytes.
[out]writtenReceives the value size (the required size for a query).
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG for missing required pointers.
TLV_ERR_INVALID_LENGTH if the value length exceeds the native size range.
TLV_ERR_BUFFER_TOO_SHORT if capacity is insufficient.

Serializes a view's tag, length and value using a writer format.

Encodes as tlv_write() does. A view does not retain the original header, so the result may differ from the bytes the view was read from; use tlv_copy_encoded() to preserve them exactly.

Requires the format's write_tag, write_length and length_size callbacks. The view's value bytes must not overlap the destination element.

Parameters
[in]viewView to serialize.
[in]formatWriter format used to encode the element.
[out]dataDestination buffer. NULL with zero capacity queries the required size.
[in]capacityDestination capacity in bytes.
[out]writtenReceives the encoded size.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG for missing required pointers or callbacks.
TLV_ERR_BUFFER_TOO_SHORT if capacity is insufficient.
Any callback error, propagated unchanged.
Warning
Callback errors may leave data modified. Size queries never write data.
See also
tlv_write, tlv_copy_encoded
