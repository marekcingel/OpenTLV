Detailed Description

One component of a SEQUENCE, SET or CHOICE, or the repeated element of a SET OF.

All pointers are borrowed and must outlive use. CHOICE alternatives must have presence TLV_DER_REQUIRED and no default (enforced by tlv_der_schema_check()).
