const tlv_query_hook_t tlv_asn1_query_date
extern

GeneralizedTime DATE provider (ID 4), UTC seconds with no fractional precision. Uses the native GeneralizedTime Value codec and additionally validates Gregorian calendar dates. Fractions are rejected, even zero fractions; no timezone guessing or silent precision loss. Scratch is an aligned tlv_asn1_generalized_time_t. The provider borrows no mutable storage and is safe for concurrent execution.
