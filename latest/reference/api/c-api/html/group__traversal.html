◆ tlv_query_matcher_t

typedef struct tlv_query_matcher tlv_query_matcher_t

Incremental matcher that decides which elements of a preorder traversal a query addresses.

This is the state behind tlv_query_walk(), exposed so that any preorder traversal can run a query, such as the DER walker or a caller's own. Set it up with tlv_query_matcher_init() and feed it every element, in order, with tlv_query_matcher_visit(). The fields are private.

◆ tlv_query_t

typedef struct tlv_query tlv_query_t

A parsed query: the tags to follow from a top-level element down to the addressed ones.

The structure is self-contained, never allocates and never points to other memory. Build it with tlv_query_parse(); a zero-initialized query has no tags and is rejected by the functions that take one.

Warning
Its layout depends on TLV_TAG_CAPACITY, so it is part of the ABI in the same way as tlv_tag_t.

◆ tlv_query_parse()

tlv_result_t tlv_query_parse ( const char *  text,
tlv_query_t *  query,
size_t *  error_offset 
)

Parses the text of a query.

The text is one or more tags in hexadecimal, separated by a single /, for example 6F/A5/50 or 9f02. Each tag has an even, nonzero number of digits in either case and at most TLV_TAG_CAPACITY bytes. Whitespace, empty steps and a leading or trailing / are rejected. The tag bytes are not checked against any format or profile.

Parameters
[in]textNUL-terminated query text.
[out]queryReceives the parsed query.
[out]error_offsetOptional. On failure receives the index in text of the offending character, or of the start of the offending tag; unchanged on success.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG if text or query is NULL.
TLV_ERR_INVALID_ARG for a syntax error: an empty step, an odd number of digits, or a character other than a hexadecimal digit or /.
TLV_ERR_INVALID_TAG_SIZE if a tag is longer than TLV_TAG_CAPACITY bytes.
TLV_ERR_LIMIT if the query has more than TLV_QUERY_MAX_STEPS tags.
Note
Never allocates. On failure *query is unchanged.

Calls a visitor for every element a query addresses.

Traverses the input in preorder like tlv_walk_tree() and calls visitor for each element addressed by query, in document order, with that element's depth (always query->count - 1) and absolute offset. An element is addressed when its tag equals the last query tag and its ancestors, from the top level down, match the earlier ones.

The whole input is traversed unless the visitor stops, so malformed data after the last match is reported like any other error. Values are only entered when is_constructed says so; with a NULL predicate only one-tag queries can match.

Parameters
[in]dataInput buffer.
[in]sizeInput size in bytes.
[in]formatReader format.
[in]is_constructedPredicate receiving format->context, or NULL to treat every value as opaque.
[in]queryParsed query.
[in]max_depthMaximum nesting depth, 0..TLV_WALK_MAX_DEPTH.
[in]max_elementsBound on all traversed elements, matching or not.
[in]visitorCallback per addressed element. Required. Its view borrows data and is valid only during the call.
[in]contextPassed to the visitor unchanged; may be NULL.
[out]error_offsetOptional. On failure receives the failing element's absolute offset; unchanged on success.
Returns
TLV_OK at the end of input, or when the visitor returns TLV_VISIT_STOP.
TLV_ERR_NULL_ARG if query or visitor is NULL, or as for tlv_walk_tree().
Any error of tlv_query_matcher_init() for an invalid query.
TLV_ERR_VISITOR if the visitor returns TLV_VISIT_ERROR or an unknown result.
Any other error of tlv_walk_tree(), propagated unchanged.
Note
Never allocates and does not recurse. No match is not an error: the visitor is simply never called.
Warning
Visitor effects are not rolled back on error. The input and format must remain valid and unchanged during the call.

Finds the first complete candidate element at or after an offset.

Tries tlv_read() at each byte offset from start through size - 1 and returns the first complete candidate. Candidate parsing and validation errors, including truncated data, are skipped.

A non-NULL schema requires a known tag and a valid value length; an empty schema rejects all candidates. With no schema only syntactic validation applies.

Parameters
[in]dataInput buffer. May be NULL only when size is zero.
[in]sizeInput size in bytes.
[in]startFirst offset to try, relative to data.
[in]formatReader format; read_tag and read_length are required.
[in]schemaOptional schema restricting candidates; may be NULL. schema->entries may be NULL only for a zero count.
[out]out_entryReceives the matched element; borrows the input value.
[out]out_offsetReceives the match offset, absolute relative to data.
[out]consumedReceives the encoded size of the match.
Returns
TLV_OK if a candidate matched.
TLV_ERR_END_OF_BUFFER if there is no match, including start >= size.
TLV_ERR_NULL_ARG for invalid arguments.
Note
All outputs remain unchanged on failure.
No allocation or value copying occurs; custom callbacks must obey the allocation-free format contract.
Warning
A match is not proof of an original element boundary. The input, format and schema must stay valid during the call, and the input must outlive the returned view.

Visits each sequential element using the generic reader.

Does not allocate or recurse into values. Returns TLV_OK at the end of input (including empty input) or on TLV_VISIT_STOP. No further elements are read after a stop or error.

Parameters
[in]dataInput buffer. May be NULL only when size is zero.
[in]sizeInput size in bytes.
[in]formatReader format; read_tag and read_length are required, even for empty input.
[in]visitorCallback invoked per element. Required.
[in]contextPassed to the visitor unchanged; may be NULL.
Returns
TLV_OK at the end of input or on TLV_VISIT_STOP.
TLV_ERR_NULL_ARG for invalid arguments.
TLV_ERR_VISITOR if the visitor returns TLV_VISIT_ERROR or an unknown result.
Any reader error, propagated unchanged.
Warning
The input and format must remain valid and unchanged during traversal. Effects of earlier callbacks are not rolled back on error.

Traverses nested elements in preorder.

Constructed values (identified by is_constructed) are traversed as bounded views of the input. There is no allocation and no C recursion. A NULL visitor validates only. TLV_VISIT_STOP succeeds immediately.

Parameters
[in]dataInput buffer.
[in]sizeInput size in bytes.
[in]formatReader format.
[in]is_constructedPredicate receiving format->context; NULL treats every value as opaque.
[in]max_depthMaximum nesting depth, 0..TLV_WALK_MAX_DEPTH.
[in]max_elementsBound on all visited nodes; zero permits only empty input.
[in]visitorCallback per element; may be NULL to validate only.
[in]contextPassed to the visitor unchanged.
[out]error_offsetOptional. On failure receives the failing element's absolute offset; unchanged on success.
Returns
TLV_OK on success or when the visitor returns TLV_VISIT_STOP.
TLV_ERR_LIMIT if max_depth exceeds TLV_WALK_MAX_DEPTH, or the depth or element limit is exceeded.
TLV_ERR_VISITOR if the visitor requests an error stop.
Any reader error, propagated unchanged.
Warning
Callback effects are not rolled back. The input, format and borrowed views follow the lifetimes documented for tlv_walk().
