Detailed Description

ASN.1 CER reader and writer formats with tag accessors.

The tag accessors here have identical semantics to the DER accessors in tlv/builtins/asn1/der.h (tlv_asn1_class_t is shared, declared in tlv/builtins/asn1/ber.h). They are duplicated rather than reused from der.h so CER never depends on the DER component being enabled.
