Detailed Description

Borrowed EMV domain dictionary for one explicitly selected context.

Native tables and caller-owned tables use the same lookup. Entries, schemas, tag bytes, names, codecs and codec contexts must remain alive and immutable while this dictionary or returned entries are used. No allocation or ownership transfer occurs. Descriptive labels remain separate from symbolic names.
