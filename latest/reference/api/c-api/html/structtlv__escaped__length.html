Detailed Description

One-byte inline count or an escape followed by a fixed-width count.

Prefixes below escape encode their own value. Prefixes above escape are invalid. The escape is followed by extended_size full bytes in byte_order. Extended counts must be at least min_extended and at most max_length. All counts, including inline ones, must not exceed max_length. Writing uses inline form whenever possible. Reading accepts configured nonminimal forms. No prefix has protocol meaning.
