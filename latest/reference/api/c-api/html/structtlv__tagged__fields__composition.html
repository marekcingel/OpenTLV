Detailed Description

Field encoding composition with identifier-selected tag-only elements.

The borrowed immutable fields, table and identifier bytes must outlive all operations. Fields must provide both reading and writing, use TLV/VALUE framing and have no bounds resolver. Table identifiers use semantic byte identity and must be encodable by fields.write_tag. Duplicate entries are harmless. Tag-only elements omit Length and require an empty Value; their source Value/Trailer ranges are present and empty immediately after Tag. No skip or stop policy is implied. No operation allocates.
