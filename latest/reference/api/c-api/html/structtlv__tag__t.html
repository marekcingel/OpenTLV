Detailed Description

A TLV tag stored as raw bytes, independent of host endianness or TLV profile.

The tag is a self-contained value with inline storage; it never points to external memory. Empty tags support raw construction and comparison, but operations that require a nonempty tag reject them.

Note
Assigning size directly may truncate before validation; use the tlv_tag_from_* construction helpers for checked size_t lengths.

uint8_t tlv_tag_t::size

Number of valid bytes in data, 0..TLV_TAG_CAPACITY.

Zero is an empty tag. Whether the bytes form a valid tag is a separate, format- or profile-specific question. uint8_t limits the supported capacity to TLV_TAG_MAX_SUPPORTED_SIZE.
