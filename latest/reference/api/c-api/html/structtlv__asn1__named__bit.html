Detailed Description

One named bit of a BIT STRING (X.680's NamedBitList notation, for example digitalSignature(0) in a KeyUsage).

Purely descriptive: unrelated to tlv_asn1_codec_bit_string's own decode/encode, which never interpret individual bit positions.
