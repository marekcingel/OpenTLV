Detailed Description

CVM Results (Book 3 Annex C6), preserved raw.

Holds the last-applied CVM's method, applied condition and outcome bytes. Book 3 Annex A Tables 39 and 40 enumerate the method and condition code points; Table 41 defines the result values (see TLV_EMV_CVM_RESULT_UNKNOWN, TLV_EMV_CVM_RESULT_FAILED and TLV_EMV_CVM_RESULT_SUCCESSFUL). The codec stores the three bytes without further validation, like FLAGS.
