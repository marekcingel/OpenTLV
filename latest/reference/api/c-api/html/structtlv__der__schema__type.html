Detailed Description

An ASN.1 type expression.

components and component_count apply to SEQUENCE, SET and CHOICE (at most TLV_DER_SCHEMA_MAX_COMPONENTS direct components). element applies to SET OF, with min_elements and max_elements (inclusive, SIZE_MAX for unbounded) bounding its element count. universal_number applies to TLV_DER_SCHEMA_UNIVERSAL leaves. Fields unused by a given kind are ignored. All pointers are borrowed and must outlive use.
