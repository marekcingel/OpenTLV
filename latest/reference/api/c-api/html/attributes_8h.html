Detailed Description

Portable declaration attributes built on tlv/compiler.h.

Each macro expands to the strongest attribute the active language standard and compiler support, using the capabilities detected by tlv/compiler.h, and degrades to nothing (or, for TLV_FALLTHROUGH, to no statement) where none apply, including the C99 baseline. A declaration written once, for example TLV_NODISCARD tlv_result_t tlv_reader_next(...), therefore keeps the same API and ABI on every supported toolchain while newer ones gain stronger compile-time diagnostics. This header defines no functions or types, only preprocessor macros, so it needs no extern "C" guard and is safe to include from both C and C++ translation units.
