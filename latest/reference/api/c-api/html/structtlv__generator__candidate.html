Detailed Description

A borrowed candidate identifier and permitted Value size interval. Constructed identifiers are classified exclusively by Format and receive generated child streams. Primitive Values contain arbitrary bytes; this is wire generation, not Schema/Codec-valid content generation. Exclude stream terminators and identifiers requiring contextual ordering from this table.
