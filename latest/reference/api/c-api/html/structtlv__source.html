Detailed Description

Immutable borrowed representation of one decoded element.

All ranges are relative to data. Header, value and trailer partition size. The source buffer, descriptor and its immutable context must outlive this value. Copying only copies descriptors. Never modify the source buffer while a source is live. Mutation of an element does not mutate this source.
