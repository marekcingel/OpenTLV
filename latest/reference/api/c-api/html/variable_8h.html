Detailed Description

Configurable variable-width identifier and count primitives.

Configurations are immutable and borrowed. No operation allocates. Identifiers retain their complete wire byte identity, including prefix bits; no numeric tag interpretation or minimality rule is imposed. Concrete formats supply their own validity rules. These primitives do not depend on any builtin.
