Validate contextual boolean assertions over immutable complete input.

Parameters
dataStable input bytes, alive through the call.
sizeInput byte count.
formatBorrowed Format/context.
rulesCompiled rules, composing with existing structural validation separately.
countRule count; zero skips assertion validation explicitly.
depthMaximum depth.
nodesExplicit retained-node capacity.
workCharged budget per execution (selector and each assertion context).
workspaceCaller storage, disjoint from input/programs.
diagnosticOptional structured failure; Reader failures remain their original codes.
Returns
OK, SCHEMA for false assertion, or native storage/Reader/Query failure.
Note
Rejects all D rules before input traversal. Every context uses the original whole input and normal Query relative-context semantics. Full structural coverage; no subtree pruning. Work is O(sum of selector and per-context assertion executions). No allocation or independent path/expression evaluator.
