◆ children

const struct tlv_structure_schema* tlv_structure_rule::children

Schema for the value's children. Requires TLV_SCHEMA_CONSTRUCTED and validates the complete value, including required children in empty containers. NULL leaves membership unrestricted, while wire structure is still checked recursively.
