Detailed Description

Borrowed composition of identifier metadata, field Schema and Value Codec. Each referenced object is authoritative for its own properties. The schema's tag must equal definition->tag; both should borrow the same canonical bytes. A dictionary selects context, without imposing a required generic pipeline. All referenced objects and their storage must remain immutable and alive while an entry is used. Builtin entries borrow static storage.
