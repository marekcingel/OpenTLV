Detailed Description

Configuration for the configurable fixed-width format.

A borrowed, immutable value: the address passed to tlv_fixed_reader_format_init() or tlv_fixed_writer_format_init() becomes the initialized format's context, so the configuration must outlive every reader or writer built from it.
