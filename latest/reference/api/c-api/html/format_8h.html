Detailed Description

Reader and writer format descriptors that define a TLV wire encoding.

A format is a pair of stateless callback tables (one for reading, one for writing) plus an optional borrowed, immutable context. Concrete formats live under tlv/formats/; custom formats are built with tlv_reader_format_init() and tlv_writer_format_init().

Callbacks must not allocate, retain buffers, or access memory beyond the size or capacity they are given. All sizes are in bytes. Tags must fit TLV_TAG_CAPACITY; unsupported tag sizes return TLV_ERR_INVALID_TAG_SIZE. Callback errors propagate unchanged through the generic reader and writer.
