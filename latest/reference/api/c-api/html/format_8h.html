Detailed Description

Canonical wire-to-element contract and borrowed source information.

Formats alone interpret wire rules. Decode produces a semantic element and framing/source information; encode regenerates a representation of that element. For a bidirectional format, successful encoding must decode to an equal identifier and equal value bytes. Exact source reproduction is the separate tlv_source_preserve() operation. No operation allocates.
