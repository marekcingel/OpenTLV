Detailed Description

Inline identifier bits with an escape into continuation octets.

One octet is sufficient unless (first & inline_mask) == escape. In that case at least one continuation octet follows, ending when continuation_bit is clear. Only payload_mask and continuation_bit may be set in those octets. Without a policy, zero payloads and nonminimal forms are accepted. Bits outside inline_mask in the first octet are preserved without interpretation.
