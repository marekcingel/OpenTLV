◆ TLV_LENGTH_MAX

#define TLV_LENGTH_MAX   UINT64_MAX

The largest value a tlv_length_t can hold.

Always UINT64_MAX, independent of build configuration or the current build's size_t width. Distinct from SIZE_MAX, which bounds what tlv_length_to_size() accepts in the current build.

◆ TLV_TAG

#define TLV_TAG (   ...)     (tlv_tag((const uint8_t[]){__VA_ARGS__}, sizeof((const uint8_t[]){__VA_ARGS__})))

Builds an allocation-free tag from literal bytes, e.g. TLV_TAG(0x9F, 0x02).

Every argument must be a constant byte value. The tag references constant storage that the compiler provides: in C++ it has static storage duration, so the tag may be stored and returned freely. In C it is a compound literal that lives until the end of the enclosing block (at file scope it is static), so do not return it or keep it beyond that block.

typedef uint64_t tlv_length_t

Logical TLV value length.

Always a 64-bit unsigned range, independent of build configuration, the current build's size_t width, or wire format.

Warning
A value may not be usable as an in-memory buffer length in the current build. Convert with tlv_length_to_size() or check with tlv_length_validate_native() before native-size use.

TLV_ERR_BUFFER_TOO_SHORT

A required pointer argument is NULL.

An allocation failed.

A visitor callback requested an error stop.

TLV_ERR_LIMIT 

A configured depth, size, or element-count limit was exceeded.

TLV_ERR_SCHEMA 

Input violates a schema rule; see tlv_schema_validate().

TLV_ERR_INVALID_ARG 

An argument has an invalid value that no more specific code describes.

TLV_ERR_INVALID_TAG_SIZE 

Tag size violates the range supported by the operation.

TLV_ERR_INVALID_BYTE_ORDER 

Byte order is unknown or unsupported.

TLV_ERR_OVERFLOW 

Unsigned value cannot fit the requested numeric width.

TLV_ERR_INVALID_VALUE 

Universal primitive content is malformed or fails a canonical DER rule.

TLV_ERR_UNSUPPORTED_TYPE 

Universal tag number has no implemented canonical validation.

TLV_ERR_SCHEMA_MISSING 

A required field is absent (tlv_schema_validate()).

Reported when a rule's min_occurs exceeds its actual occurrence count. It is distinct from TLV_ERR_SCHEMA because its error offset is the end of the enclosing parent's value: a scope boundary, not an element. That offset can coincide with the start of an unrelated sibling in the parent scope, so a tag read there is not reliably the cause.

Every other tlv_schema_validate() violation (forbidden or unknown tag, duplicate or excess occurrence, kind mismatch, invalid rule table) returns TLV_ERR_SCHEMA with an offset anchored to the actual element.

◆ tlv_read_uint()

tlv_result_t tlv_read_uint ( const uint8_t *  data,
size_t  width,
tlv_byte_order_t  order,
uint64_t *  value 
)

Reads an unsigned integer of 1..8 bytes with an explicit byte order.

Accepts zero padding. The read finishes before *value is stored. There is no allocation, implicit native byte order, or protocol validation. Byte buffers need no alignment.

Validation order: required NULL pointers, then the width, then the byte order.

Parameters
[in]dataSource bytes; width readable bytes. Allocation bounds are not checked.
[in]widthNumber of bytes, 1..8.
[in]orderByte order of the bytes.
[out]valueReceives the value; must point to a writable uint64_t.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG if a required pointer is NULL.
TLV_ERR_INVALID_LENGTH if width is unsupported.
TLV_ERR_INVALID_BYTE_ORDER if order is unknown or unsupported.
Note
On failure *value is unchanged.

◆ tlv_tag_compare()

int tlv_tag_compare ( tlv_tag_t  lhs,
tlv_tag_t  rhs 
)

Orders two tags lexicographically by their bytes.

Compares byte by byte as unsigned values; if one tag is a prefix of the other, the shorter tag orders first. The bytes are never interpreted as an integer, so the result does not depend on host endianness.

Precondition
Both tags are valid: data is not NULL when size > 0.
Parameters
[in]lhsFirst tag.
[in]rhsSecond tag.
Returns
A negative value if lhs orders before rhs, zero if the tags are equal, and a positive value if lhs orders after rhs.

Copies a tag's bytes into caller-owned storage.

With data == NULL and capacity == 0, reports the required size in *written without copying. Overlapping source and destination byte ranges are supported.

Parameters

[out]dataDestination buffer. NULL with zero capacity queries the required size.

tlv_result_t tlv_write_uint ( uint8_t *  data,
size_t  width,
tlv_byte_order_t  order,

)

Writes an unsigned integer as 1..8 bytes with an explicit byte order.

Zero-pads to width and never truncates. Byte buffers need no alignment. There is no allocation, implicit native byte order, or protocol validation. Validation order: required NULL pointers, then the width, then the byte order, then whether the value fits.

Parameters
[out]dataDestination; width writable bytes. Allocation bounds are not checked.
[in]widthNumber of bytes, 1..8.
[in]orderByte order to write.
[in]valueValue to write.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG if data is NULL.
TLV_ERR_INVALID_LENGTH if width is unsupported.
TLV_ERR_INVALID_BYTE_ORDER if order is unknown or unsupported.
TLV_ERR_OVERFLOW if value does not fit in width bytes.
Note
On failure the destination is unchanged.
