Detailed Description

Structured diagnostic model shared across OpenTLV layers: a stable code, severity, location and nested context, independent of any wire format or protocol. Guides: diagnostics.

typedef struct tlv_diagnostic_context tlv_diagnostic_context_t

One piece of context a layer has attached to a tlv_diagnostic_t.

A context node is caller-provided storage linked onto a diagnostic's contexts chain by tlv_diagnostic_add_context(); nothing is copied or allocated. layer, key and value are borrowed and must stay valid, and context itself must stay valid and unmoved, for as long as the diagnostic is used.

◆ tlv_diagnostic_path_t

typedef struct tlv_diagnostic_path tlv_diagnostic_path_t

Bounded, allocation-free stack of the tags enclosing a tlv_diagnostic_t.

A caller that traverses nested constructed TLVs, for example with tlv_walk_tree() or by recursing into a value's bytes, builds a path by calling tlv_diagnostic_path_push() with the tag of each element it descends into and tlv_diagnostic_path_pop() when it returns to the parent. tags then lists the enclosing elements outermost first, so it identifies the exact branch of a document that led to a diagnostic even when the same tag repeats at different depths. Nothing is copied or allocated: pushing a tag stores its borrowed data/size pair, which must stay valid, and unchanged, for as long as the path is used.

Path tracking is entirely opt-in: a tlv_diagnostic_t that is never given a path costs nothing beyond the one NULL pointer in path.

◆ tlv_diagnostic_t

typedef struct tlv_diagnostic tlv_diagnostic_t

A structured diagnostic: a stable code plus the state that produced it.

The core representation is independent of any wire format, schema or higher-level protocol. A format, schema, profile or application layer enriches a diagnostic that a lower layer produced by chaining tlv_diagnostic_context_t entries onto contexts with tlv_diagnostic_add_context(), instead of defining its own diagnostic type. Rendering a diagnostic for humans is a separate concern, not part of this type.

Every field is a fixed-size value or a borrowed pointer; a diagnostic never allocates and never owns the memory it points to.

Attaches one context entry to a diagnostic.

Links context onto the front of diagnostic->contexts, so the most recently added context is innermost. Nothing is copied or allocated.

Parameters
[in,out]diagnosticDiagnostic to update; must not be NULL.
[out]contextCaller-owned storage for the new entry; must not be NULL. Every field is overwritten.
[in]layerBorrowed name of the layer adding context, for example "ber".
[in]keyBorrowed name of the attribute, for example "declared_length".
[in]valueBorrowed formatted value of the attribute.
Warning
context and the strings passed in must stay valid, and context must stay at the same address, for as long as the diagnostic is used.

tlv_result_t tlv_diagnostic_path_string ( const tlv_diagnostic_path_t *  path,
char *  out,
size_t  capacity,
size_t *  length 
)

Formats a path as uppercase hexadecimal tags joined by " > ".

For example "6F > A5 > BF0C > 61 > 4F". An empty path formats as an empty string. The text is NUL-terminated when it fits.

Parameters
[in]pathPath to format.
[out]outDestination; may be NULL only if capacity is zero.
[in]capacitySize of out in bytes, including the terminator.
[out]lengthReceives the text length without the terminator, also when out is too small. May be NULL.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG if path or a required out is NULL.
TLV_ERR_INVALID_ARG if path->length exceeds TLV_DIAGNOSTIC_PATH_MAX or a tag in path is invalid.
TLV_ERR_BUFFER_TOO_SHORT if capacity is below *length + 1.
