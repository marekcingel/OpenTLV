Static native generic NUM/BCD/TEXT providers, IDs 1/2/3. NUM uses minimal signed big-endian int64; BCD uses unsigned packed decimal with at most 18 digits; TEXT uses borrowed UTF-8 bytes. Domain codecs may replace these by explicit adapters and distinct stable capability IDs.

Returns
Borrowed immutable provider array.
