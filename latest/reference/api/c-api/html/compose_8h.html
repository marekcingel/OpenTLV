Detailed Description

Public field composition primitives for canonical formats.

These primitives compose field encodings into a single decode/measure/encode contract. Reader and Writer never inspect the composition. Context and encoding configuration remain borrowed and immutable. Callbacks do not allocate. These types configure Format composition; runtime ranges of a decoded element are represented separately by tlv_source_t and tlv_range_t.
