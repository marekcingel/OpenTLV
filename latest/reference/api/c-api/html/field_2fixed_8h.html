Detailed Description

Fixed-width raw identifiers and unsigned count encodings.

Configurations are immutable and borrowed for each call. Operations do not allocate or retain configuration pointers. Identifiers preserve raw byte identity; byte order applies only to counts. Element placement, count scope, framing and protocol policy belong to the caller's Format composition.
