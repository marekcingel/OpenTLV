Detailed Description

Borrowed field codec composition for a contiguous header and value.

The optional bounds resolver supports terminated values on the TLV path. It returns a validated trailer; formats with an encoder-dependent trailer implement the canonical measure/encode operations directly instead. A count including the identifier is normalized here, not in Reader/Writer.
