Detailed Description

Reader-specific failure evidence without common diagnostic metadata.

Note
Fields with a zero has_* flag are unset. Tag and raw-length bytes borrow the original wire storage, which must outlive this detail. The tag is the wire envelope reported by Format, not a transformed semantic identifier.
This fixed-size value contains no result, location or path. It can be embedded beside one shared tlv_diagnostic_t without duplicating that storage.
