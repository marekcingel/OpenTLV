Detailed Description

Format-produced failure detail, initialized to zero before invoking callbacks.

The core initializes callback storage. Public operation output guarantees are documented on the individual entry points.

Note
Read this detail only after a failing result. Builtin callbacks write it only on failure, from state they already hold, so successful decoding does no diagnostic work. Custom callbacks may do the same.
