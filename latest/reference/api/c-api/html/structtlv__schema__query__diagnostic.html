Detailed Description

Rule-aware failure preserving native Query/Reader/codec diagnostics.

Note
After initialization, a failed assertion sets schema.diagnostic.code to the return code; an execution failure sets query.kind to a non-NONE category. Preflight rejection before initialization leaves both untouched.
