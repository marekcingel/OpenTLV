Detailed Description

Stateless writing format with optional borrowed, immutable configuration.

The descriptor and context must outlive every writer and operation that uses them. write_tag, write_length and length_size are all required unless write_header is set, which replaces the three. Callbacks must not allocate, retain buffers, or access memory beyond capacity. Successful write callbacks initialize written. Value encoding is a separate concern.
