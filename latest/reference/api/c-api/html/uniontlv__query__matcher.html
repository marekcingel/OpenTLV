Detailed Description

Incremental matcher that decides which elements of a preorder traversal a query addresses.

This is the state behind tlv_query_visit_buffer(), exposed so that any preorder traversal can run a query, such as the DER validation traversal or a caller's own. Set it up with tlv_query_matcher_init() and feed it every element, in order, with tlv_query_matcher_visit(). The fields are private.
