struct  tlv_text_codec_config
 Immutable borrowed text-codec configuration, independent of tags. Width zero selects variable-width text. Nonzero width selects a fixed-width representation. With padding enabled, decode strips trailing zero bytes and encode pads to that width; otherwise text must occupy the entire width. Embedded zeros are rejected. Field-length limits belong to Schema. typedef struct tlv_text_codec_config tlv_text_codec_config_t

Immutable borrowed text-codec configuration, independent of tags. Width zero selects variable-width text. Nonzero width selects a fixed-width representation. With padding enabled, decode strips trailing zero bytes and encode pads to that width; otherwise text must occupy the entire width. Embedded zeros are rejected. Field-length limits belong to Schema. Configuration must outlive its codec.
