Navigation

Nodes form a tree. Top-level nodes have no parent, and the children of a node are in encoding order. Every function returns NULL when there is no such node, and for a NULL argument.

Encoding

Encoding runs every element through the writer format. Sizes and bytes agree with tlv_encoded_size() and tlv_write(), and constructed values are written from their children, so no length is stored that could go stale.

Detailed Description

Optional owned tree of elements that can be searched, changed and encoded again; the only allocating component. Guides: mutable documents.

Finds the first element addressed by a path query.

Uses the query language of tlv_query_parse(), for example 6F/A5/50: the first tag names a top-level element, each further tag one of its direct children. The elements addressed by the query are searched in document order, and a step that leads to a dead end does not hide a later match.

Parameters

[in]queryParsed query.
Returns
The first addressed node, or NULL if none, or if an argument is NULL or the query is empty.

Inserts a new element.

The tag and value are copied. As with tlv_node_set_value(), the value of a tag that is_constructed accepts is parsed as nested elements. The tag is checked with the writer format, so a tag it cannot write is rejected here.

Parameters
[in,out]documentDocument to change.
[in]parentConstructed node that receives the element, or NULL for the top level.
[in]beforeExisting child of parent that the new node precedes, or NULL to append at the end.
[in]tagTag of the new element.
[in]valueValue bytes. May be NULL only when length is zero.
[in]lengthValue length in bytes.
[out]nodeOptional. Receives the new node.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG for a NULL document, a NULL value with a nonzero length, or a tag with a NULL pointer and nonzero size.
TLV_ERR_INVALID_ARG if parent is primitive or belongs to another document, or before is not a child of parent.
TLV_ERR_LIMIT if the depth or element limit would be exceeded.
TLV_ERR_OUT_OF_MEMORY if memory is exhausted.
Any writer format error for the tag, or reader error for a constructed value.

◆ tlv_document_parse()

tlv_result_t tlv_document_parse ( const uint8_t *  data,
size_t  size,
const tlv_document_options_t *  options,
tlv_document_t **  document,
size_t *  error_offset 
)

Parses encoded elements into a new owned document.

Reads the whole input with the reader format. Values of tags that is_constructed accepts are parsed as nested elements, up to max_depth. Tags and values are copied, so the input may be released or reused after the call. Empty input gives an empty document.

Parameters
[in]dataEncoded input. May be NULL only when size is zero.
[in]sizeInput size in bytes.
[in]optionsFormat descriptor and limits; copied.
[out]documentReceives the document; free it with tlv_document_free(). Set to NULL on failure.
[out]error_offsetOptional. On failure of the input, receives the absolute offset of the offending element; unchanged otherwise.
Returns
TLV_OK on success.
Any error of tlv_document_create().
TLV_ERR_LIMIT if the depth or element limit is exceeded.
Any reader error, propagated unchanged.
Note
Nothing is retained on failure: everything allocated so far is released.

Replaces the value of a node.

For a primitive node the bytes are copied. For a constructed node the bytes are parsed as nested elements with the document's reader format, and replace all children, as if the node had been read from such an encoding.

Parameters
[in,out]nodeNode to change.
[in]valueNew value bytes; copied. May be NULL only when length is zero.
[in]lengthValue length in bytes.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG for a NULL node, or a NULL value with a nonzero length.
TLV_ERR_LIMIT if the depth or element limit would be exceeded.
TLV_ERR_OUT_OF_MEMORY if memory is exhausted.
Any reader error for a constructed node's value.
Warning
Invalidates the previous value pointer of the node, and for a constructed node every child pointer.
