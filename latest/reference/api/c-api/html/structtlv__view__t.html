Detailed Description

A decoded TLV element: an inline tag and a borrowed value.

The tag is stored inline. The value borrows the original input storage, so copying a view copies the tag but neither copies the value bytes nor extends their lifetime; the input must outlive every copy of the view.

Note
This plain type does not validate its fields or impose a wire format.
