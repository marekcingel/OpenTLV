const tlv_definition_t * tlv_definition_find ( const tlv_definition_registry_t *  registry,
const tlv_tag_t *  tag 
)

Finds the first definition with the same tag size and bytes.

Uses tlv_tag_equal(), including its empty-tag equality. Invalid entry tags are skipped. No sorting is required and no allocation occurs. A missing definition does not make an identifier structurally invalid.

Parameters
[in]registryRegistry to search; may be NULL.
[in]tagIdentifier to find; may be NULL.
Returns
A borrowed pointer to the first matching entry.
NULL for an unknown tag, NULL arguments, an invalid lookup tag, or a missing nonempty table.
