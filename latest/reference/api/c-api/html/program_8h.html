Detailed Description

Caller-stored immutable Query programs and bounded S0 event execution.

Note
All calls are allocation-free and iterative. Storage must be aligned to the reported alignment, alive and unchanged while borrowed. Internal program images are release-specific, not a persistent serialization format.
