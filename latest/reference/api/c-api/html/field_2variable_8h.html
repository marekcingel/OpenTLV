Detailed Description

Configurable variable-width identifier and count primitives.

Configurations are immutable and borrowed. No operation allocates. Identifiers retain their complete wire byte identity, including prefix bits; no numeric tag interpretation is imposed. Optional declarative policies constrain wire encodings; protocol semantics remain in concrete formats. These primitives do not depend on any builtin.
