Detailed Description

One violation found by tlv_schema_validate_all().

path lists the tags from the outermost scope to the affected tag, for example 70, 77, 9F36 for the text 70/77/9F36. For TLV_SCHEMA_ISSUE_MISSING the last entry is the tag that is absent.
