Detailed Description

Original encoded length bytes, without numeric interpretation.

Borrows size bytes in wire order. The source must remain valid and unchanged while this descriptor or any copy is used. No allocation or byte copying occurs. size is a native memory extent, not a decoded quantity. The selected format interprets these bytes; a marker for a terminated value is preserved as-is. { NULL, 0 } denotes an absent length field.
