struct  tlv_emv_definition_t
 Borrowed composition of identifier metadata, field Schema and Value Codec. Each referenced object is authoritative for its own properties. The schema's tag must equal definition->tag; both should borrow the same canonical bytes. A dictionary selects context, without imposing a required generic pipeline. All referenced objects and their storage must remain immutable and alive while an entry is used. Builtin entries borrow static storage. More...

Detailed Description

EMV Contact Book 3 data dictionary: tag constants, schemas and lookup.

Scope: EMV Contact Book 3 v4.4, October 2022, Annex A and the nested biometric tags in Annex C. No Contactless kernels, proprietary dictionaries, or subsequent specification bulletins. Untagged data elements are not tags.

Use tlv_format_emv with generic I/O for definite EMV framing. Every tag constant borrows constant static bytes and is always available.
