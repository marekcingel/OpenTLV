Detailed Description

Allocation-free Bluetooth Manufacturer Specific Data value codec.

Independent of AD framing, schema and Company Identifier definitions. Manufacturer payloads are opaque; no vendor protocol is interpreted. Use tlv_codec_decode() and tlv_codec_encode(); their NULL, overlap and size-query contracts apply. Input and output (including borrowed storage) must not overlap. Supply correctly typed and aligned representation objects. Decode requires at least sizeof(object); encode requires exactly sizeof(object). Decode preserves the destination on error. Encode reports written == 0 on error.

Note
Requires OPENTLV_BLUETOOTH=ON.
