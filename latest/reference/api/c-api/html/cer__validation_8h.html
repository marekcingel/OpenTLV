Detailed Description

Bounded recursive CER validation, traversal and canonical writing.

All functions here are allocation-free and use no C recursion. All limits are inclusive, and zero is a real limit. Passing NULL limits selects tlv_cer_default_limits.

A valid max_depth beyond the fixed implementation capacity returns TLV_ERR_UNSUPPORTED. Exceeding an accepted processing budget returns TLV_ERR_LIMIT. Unknown visitor results return TLV_ERR_CALLBACK.
