Detailed Description

Borrowed set of structural rules for one parent scope.

Rules apply within one parent only, and tags must be unique in each table. Unknown tags are rejected unless allow_unknown is nonzero.

Warning
Rule tables are borrowed and must stay valid and unchanged while in use.
