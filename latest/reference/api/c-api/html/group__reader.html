typedef struct tlv_reader_diagnostic tlv_reader_diagnostic_t

Structured detail for a failed tlv_read() or tlv_reader_next() call.

Pairs a tlv_diagnostic_t with the reader-specific state needed to locate a parsing failure precisely: which step failed, the tag being processed if one was already decoded, the offsets of the fields involved, and the sizes that made the operation fail. Every field is a fixed-size value or a borrowed pointer, so filling one never allocates; tag, like any tlv_tag_t a reader produces, borrows the input buffer that was parsed.

A field not applicable to the failure that produced the diagnostic is left unset, indicated by its paired has_* flag being zero.

Initialize with tlv_reader_init(). The reader borrows its buffer and format; neither is copied, and both must outlive the reader.

Parses one element from the beginning of a buffer.

Trailing bytes after the element are ignored. On success out_entry borrows the input value (zero-copy) and consumed receives the complete encoded size (tag + length + value + optional trailer). The value excludes enclosing framing such as BER EOC. No allocation, value copying, or schema validation occurs.

Parameters
[in]dataEncoded input. May be NULL only when size is zero, which returns TLV_ERR_END_OF_BUFFER.
[in]sizeInput size in bytes.
[in]formatReader format; its read_tag and read_length callbacks are required.
[out]out_entryReceives the parsed element. Required.
[out]consumedReceives the encoded size of the element. Required.
Returns
TLV_OK on success.
TLV_ERR_NULL_ARG for missing required pointers or callbacks.
TLV_ERR_END_OF_BUFFER for empty input.
TLV_ERR_INVALID_TAG if the tag is truncated.
TLV_ERR_INVALID_TAG_SIZE for an empty tag or an unsupported tag size.
TLV_ERR_INVALID_LENGTH if the length field is truncated.
TLV_ERR_BUFFER_TOO_SHORT if the value or trailer is truncated.
Any callback error, propagated unchanged.
Note
On failure both outputs remain unchanged.
Warning
The caller must keep data alive while out_entry->value is used.

Parses one element from the beginning of a buffer, with diagnostic detail on failure.

Behaves exactly like tlv_read(); additionally, when out_diagnostic is not NULL and parsing fails, it is filled with detail about the failure.

Parameters
[in]dataEncoded input. May be NULL only when size is zero.
[in]sizeInput size in bytes.
[in]formatReader format; its read_tag and read_length callbacks are required.
[out]out_entryReceives the parsed element. Required.
[out]consumedReceives the encoded size of the element. Required.
[out]out_diagnosticReceives detail on failure; may be NULL.
Returns
Same as tlv_read().
Note
On failure both out_entry and consumed remain unchanged.
On success *out_diagnostic is left unchanged.
Warning
The caller must keep data alive while out_entry->value or out_diagnostic->tag is used.

Reads the next TLV element and advances the reader.

On success *out_entry is set and the position advances. The tag is copied into the view; the value points directly into the original buffer (zero-copy).

Parameters
[in,out]readerReader to advance.
[out]out_entryReceives the next element.
Returns
TLV_OK on success.
Any error of tlv_read() otherwise.
Note
On error both the reader position and *out_entry remain unchanged.
Warning
The caller must keep the original buffer alive while the returned view is used.

Reads the next TLV element and advances the reader, with diagnostic detail on failure.

Behaves exactly like tlv_reader_next(); additionally, when out_diagnostic is not NULL and the read fails, it is filled with detail about the failure. Offsets in *out_diagnostic are absolute within the reader's buffer, not relative to the element that was being read.

Parameters
[in,out]readerReader to advance.
[out]out_entryReceives the next element.
[out]out_diagnosticReceives detail on failure; may be NULL.
Returns
Same as tlv_reader_next().
Note
On error the reader position and *out_entry remain unchanged.
On success *out_diagnostic is left unchanged.
