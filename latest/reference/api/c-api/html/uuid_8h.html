Detailed Description

Allocation-free Bluetooth UUID value and list codecs.

All descriptors have static lifetime and work independently of AD Types, the Bluetooth format, schema and registry. Wire UUIDs are little-endian. No codec changes the source bytes or allocates. Use tlv_codec_decode() and tlv_codec_encode(); their NULL, overlap, size-query and error contracts apply. Supply correctly typed and aligned objects. Decode requires at least the representation's sizeof; encode requires exactly its sizeof. Incorrect wire lengths or object sizes return TLV_CODEC_ERR_INVALID_VALUE; insufficient output capacity returns TLV_CODEC_ERR_BUFFER_TOO_SHORT. UUID assignments, versions and variants are not validated or normalized.
