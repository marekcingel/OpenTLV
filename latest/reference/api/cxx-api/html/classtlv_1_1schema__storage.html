Detailed Description

template<size_t Capacity, size_t Groups = 0>
class tlv::schema_storage< Capacity, Groups >

Stationary caller-owned Schema tables with bounded capacity.

Template Parameters
CapacityMaximum rule count.
GroupsMaximum alternative-group count.
Note
Successful construction and validation allocate nothing. A capacity error throws std::length_error, whose construction may allocate.
Warning
Identifier bytes, names and child Schema storage remain borrowed. Keep them and this storage alive and unchanged through all dependent validations.
