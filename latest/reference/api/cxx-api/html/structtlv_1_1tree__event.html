Detailed Description

Canonical borrowed BEGIN, ELEMENT or END event.

Reader BEGIN carries a complete Value; Writer builds the parent Value from subsequent events. END has no borrowed payload. Source is optional producer metadata and does not affect encoding. Copying allocates nothing.

Warning
BEGIN/ELEMENT input, Format-supplied identifier storage and source Format/context must outlive every retained copy. END needs no parent storage.
