Detailed Description

template<typename F>
class tlv::format_adapter< F >

Stable allocation-free adapter owning an immutable C++ Format value.

Template Parameters
FFormat implementing format_traits.

Use view() with Tree Reader/Writer, Document, Query and free algorithms. The adapter and any storage borrowed by F must outlive consumers and retained Elements/sources. Copying and moving are prohibited to preserve descriptor and context addresses. F construction may allocate; the adapter itself allocates no heap storage and processing never copies F.
