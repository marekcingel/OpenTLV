Detailed Description

template<size_t N, size_t P>
class tlv::static_query::plan< N, P >

Owned inline native plan, suitable for static constexpr storage.

Template Parameters
NInstruction count.
PPayload byte count.
Note
A borrowed program never extends this object's lifetime. Keep this object immutable and alive through every program and execution that borrows it.
