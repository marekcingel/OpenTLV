Detailed Description

Registry for types that must be decoded at runtime.

Complements the compile-time TlvCodec concept. Useful, for example, for pluggable formats whose types are not all known at compile time.

Note
Registering and decoding may allocate. The registry copies the bytes of every registered tag, so the tag passed to register_decoder() only has to stay valid for the duration of the call.
