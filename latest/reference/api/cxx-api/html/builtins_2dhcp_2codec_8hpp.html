Detailed Description

C++ DHCPv4 Message Type codec and field.

Codecs interpret Value only, delegate validation to the canonical C engine, and implement the generic typed-field contract. Successful operations allocate nothing. Borrowed results require immutable input to outlive every retained copy. Encode storage must be disjoint from all borrowed input; nullptr/0 validates and measures. Codec errors are propagated unchanged.
