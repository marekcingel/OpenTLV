Detailed Description

Immutable runtime Format owner with explicit borrowed views.

Construction and copying allocate nothing. A copy owns independent configuration. Readers, Writers and retained source information borrow the particular owner from which view() was obtained. Keep that owner alive and unmoved until all borrows end. Assignment is disabled so existing views cannot silently change configuration.
