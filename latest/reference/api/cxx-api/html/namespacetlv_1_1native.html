Detailed Description

Explicit C interoperability; ordinary C++ code uses public C++ types.

Explicit interoperability with native Schema tables and diagnostic storage.

Validates a structure and reports every schema violation as a schema_diagnostic.

Wraps tlv_schema_validate_all_diag(); the rules, order and storage conventions follow the C diagnostic report. Each diagnostic carries the schema field name (if the rule has one) and the expected-versus-actual detail for its kind.

Parameters
dataEncoded input; borrowed.
formatReader format. A nullptr format.is_constructed treats values as opaque.
schemaStructural schema; borrowed.
max_depthMaximum nesting depth.
max_elementsMaximum total elements.
diagnosticsDestination for the first capacity violations; may be nullptr only if capacity is zero.
capacityNumber of entries diagnostics can hold.
unknownPolicy for tags without a rule.
diagnosticOptional fatal failure detail, including location and definition indices.
Returns
The total number of violations, which is zero if the data conforms and can exceed capacity; otherwise the error of tlv_schema_validate_all_diag() for invalid arguments or unparseable input.
