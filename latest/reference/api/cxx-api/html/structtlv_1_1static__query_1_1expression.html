Materialize a source-free native plan; constexpr evaluates at compile time.

Returns
Owned inline plan; conflicting parameter types reject constant evaluation.
Note
Node plans include an explicit virtual root and path join, preserving absolute-path semantics even when execution has a relative context. These two instructions count toward the native 128-instruction limit.
