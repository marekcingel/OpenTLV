Detailed Description

template<typename T, typename E>
class tlv::expected< T, E >

Minimal move-only result holding either a value or an error.

Pre-C++23 stand-in for std::expected. Check has_value() (or the bool conversion) before dereferencing; accessing the wrong alternative is undefined behavior.
