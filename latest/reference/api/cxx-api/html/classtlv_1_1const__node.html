Detailed Description

Read-only checked Node handle; cannot recover mutable Node or native storage. Copies allocate nothing and retain the same validity and borrowed-view rules as node.

Warning
Read-only access does not imply thread safety. Const methods may update the validity cache after a Document mutation; concurrent access to the same handle requires external synchronization even when the Document is no longer mutating.
