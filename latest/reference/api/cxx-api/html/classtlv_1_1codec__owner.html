Detailed Description

template<typename Codec>
class tlv::codec_owner< Codec >

Stationary owner adapting a stateful C++ Value codec to runtime selection.

Template Parameters
CodecImmutable codec exposing value_type, const noexcept decode(bytes) returning expected<value_type, codec_failure>, and const noexcept encode(const value_type&, byte*, size_t) returning expected<size_t, codec_failure>.
Note
Nonthrowing static typed codecs also satisfy this contract. The adapter allocates nothing; state construction follows Codec's own policy. No native callback tables are required.
Warning
Views borrow this owner. Decode results may borrow the input Value bytes.
