Detailed Description

C++11 typed fields and tag-independent Value codec customization.

A codec exposes value_type, decode(bytes) returning expected<value_type, tlv_codec_result_t>, and encode(const value_type&, byte*, size_t) returning expected<size_t, tlv_codec_result_t>. Encode with nullptr and zero capacity validates and measures the value. Implementations must respect capacity and report the exact byte count. Input and output must not overlap. Schema owns contextual length, occurrence and nesting constraints.
