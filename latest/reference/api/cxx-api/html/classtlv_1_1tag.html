Detailed Description

Read-only borrowed identifier with byte identity, independent of Format.

Copies retain the same immutable storage; they never allocate or copy bytes. Storage must outlive every copy. A default tag is absent; a non-null empty span is an explicitly empty identifier. Equality treats both as empty, while source preservation retains this distinction. No numeric normalization occurs.
