Borrow a byte sequence or text and write it under a semantic Tag.

Parameters
tagIdentifier, borrowed for this call.
valueByte/uint8_t array or contiguous container, Value view, string, or string_view (C++17). Character arrays omit one trailing NUL, retaining embedded NULs; strings use their explicit size. Inputs must not overlap output.
Returns
Canonical Writer result; error message construction may allocate.
Note
No Value conversion allocates. Numbers require an explicit value codec; encode them into caller storage before writing the resulting bytes.
