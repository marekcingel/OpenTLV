Detailed Description

A parsed path query such as 6F/A5/50.

Wraps tlv_query_t; the query language is described in tlv/query/query.h. The object is a small self-contained value; it never allocates and does not refer to the text it was parsed from.

Calls a visitor for every element the query addresses.

Wraps tlv_query_walk(): elements are visited in document order and the rules for limits, offsets and errors are the same. Nothing is allocated and the entries passed to the visitor borrow data.

Template Parameters
VisitorCallable invoked as visitor(entry, depth, absolute_offset) returning tlv_visit_result_t, as for walk_tree().
Parameters
dataEncoded input; borrowed.
formatReader format.
is_constructedNesting predicate receiving format.context, or nullptr to treat every value as opaque, in which case only one-tag queries can match.
max_depthMaximum nesting depth, 0..TLV_WALK_MAX_DEPTH.
max_elementsBound on all traversed elements.
visitorVisitor callable; returning TLV_VISIT_STOP succeeds immediately, TLV_VISIT_ERROR fails.
error_offsetOptional. On failure receives the failing element's absolute offset; unchanged on success.
Returns
Success, also when nothing matched, or the error of tlv_query_walk().
Warning
Visitor side effects are not rolled back on error.
