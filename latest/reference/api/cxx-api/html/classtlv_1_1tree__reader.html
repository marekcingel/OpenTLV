Detailed Description

Bounded preorder traversal with incremental input and subtree control.

Warning
Input, Format and context must outlive returned views. Frames must remain writable and alive throughout traversal and must not overlap input. Pull operations and returned structured errors do not allocate. Only the last successful explicit next() selects a subtree for Document building. Every pull, skip, input replacement, validation, visitor or builder creation attempt invalidates the previous selection, including failed attempts.
