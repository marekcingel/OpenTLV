Detailed Description

template<size_t ScratchCapacity, size_t Depth = TLV_TREE_DEFAULT_DEPTH>
class tlv::writer_storage< ScratchCapacity, Depth >

Fixed-capacity, caller-owned workspace with no dynamic storage.

Template Parameters
ScratchCapacityAvailable staging bytes, including zero for flat output.
DepthNumber of simultaneously open parents.
Warning
This stationary storage must outlive every Writer borrowing it.
