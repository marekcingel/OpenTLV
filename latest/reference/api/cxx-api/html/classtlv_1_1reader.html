Detailed Description

template<typename F = tlv::format>
class tlv::reader< F >

Generic sequential reader using the canonical C engine.

Template Parameters
FC++ Format implementing format_traits; format selects a borrowed runtime view.

Supports consuming, single-pass C++11 iteration over element_view. Only final EOF ends iteration; other outcomes throw parse_error. Explicit cursor operations retain expected-based error handling.

Warning
For typed Formats this cursor owns a stable adapter and cannot be copied or moved. It and all Format-borrowed storage must outlive retained results.
