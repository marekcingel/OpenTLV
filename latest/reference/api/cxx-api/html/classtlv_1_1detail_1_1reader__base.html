◆ begin()

iterator tlv::detail::reader_base::begin ( )

Consume and publish the next element at the current cursor position.

Returns
Input iterator, or end() only on genuine final EOF.
Exceptions
parse_errorOn initialization, decoding or incremental-input failure.
Note
Each begin() consumes another element; it never rewinds. break leaves the published element consumed. Only one traversal may be active at a time.
Warning
Advancing any iterator invalidates its other copies. Explicit next(), next_source(), visit(), successful set_input(), and cursor destruction invalidate active iterators. Input and Format storage must outlive retained Element views.

inline

Reads the next element and advances the reader.

The returned element's value borrows the original buffer.

Returns
The next element, or an error: TLV_ERR_NULL_ARG if the reader failed to initialize, TLV_ERR_END_OF_BUFFER when no further element exists, or any error of tlv_reader_next().
Note
On error the reader position is unchanged.
