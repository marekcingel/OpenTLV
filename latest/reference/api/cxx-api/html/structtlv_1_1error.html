Detailed Description

Allocation-free operation error with optional absolute byte offset.

Text is borrowed, normally from immutable program-lifetime library strings. Custom descriptions must outlive every error copy. Numeric context is copied.

Note
Every error contains a full inline diagnostic path. Its storage also contributes to sizeof(expected<T, error>) for successful results, although success does not construct an error. Check sizes when budgeting stack or retained results.
