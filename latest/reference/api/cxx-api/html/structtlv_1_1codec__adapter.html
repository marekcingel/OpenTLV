Detailed Description

template<typename T, const tlv_codec_t * Descriptor>
struct tlv::codec_adapter< T, Descriptor >

Adapt a C Value descriptor with its exact C representation.

Template Parameters
TExact representation expected by Descriptor; default constructible.
DescriptorProgram-lifetime C codec, never selected by enclosing tag.
Warning
A descriptor returning borrowed data retains the input lifetime.
