# OpenTLV logo

The three blocks represent Tag, Length, and Value; the open enclosure groups
these fields into a TLV element. The logo follows the initial project concept.

- [README SVG with a white background](opentlv.svg)
- [Light-background SVG](opentlv-light.svg)
- [Dark-background SVG](opentlv-dark.svg)

The light and dark variants have transparent backgrounds and a `720 x 160`
view box. The README uses ordinary Markdown image syntax with `opentlv.svg`,
a self-contained version with a white background and a default width of 480 px.
This avoids relying on HTML `<picture>` support in Markdown previews and keeps
the wordmark readable on either editor theme. Use meaningful alternative text
when embedding the logo. The wordmark uses Arial with Helvetica/sans-serif
fallbacks; the source remains editable. Assets use the repository's
[MIT license](../../LICENSE).
